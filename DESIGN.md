# Bypax Design System (Track 2 -- Studio Slate)

> Status: LOCKED for Phase 3 implementation and Gate A/B/C acceptance.
> Visual Direction: **Track 2 -- Studio Slate** (Cool-Neutral Apple/Slate Canvas + Full-Rainbow Overpass X Brand Mark).
> Interaction Heritage: Desktop-converged friendly radii (`6px-18px`), restrained spring segmented sliders, hover-reveal row actions, and elevated active navigation cards -- without warm color temperature.

---

## 1. Visual Direction & Architectural Thesis

- **Personality:** Calm Precision & Daily-Driver Clarity ("Arc tactile craft, Apple/Slate temperature").
- **Color Temperature:** Strictly cool-neutral Slate canvas (`#F6F7F9` / `#FFFFFF` / `#0F172A` Light; `#0B1120` / `#0D1117` / `#161B22` Dark). The full-color Bypax Rainbow Overpass X is the sole high-chroma focal accent; all UI chrome stays cool-neutral so the entire warm spectrum (`amber`, `orange`, `red`) remains uncontested for latency tiers, warnings, HVCI recovery banners, and `Reject` rules.
- **L-Shaped Chrome Geometry:** Continuous `--bg-chrome` frameless TitleBar (`44px`) and responsive Sidebar cradling an inset `--bg-canvas` workspace with `border-top-left-radius: 14px` and a mandatory `1px solid var(--border-hairline)` top and left border.
- **Zero-Jargon Product Language:** User-facing copy never mentions `sing-box`, `portline`, `bypath`, `WFP`, `auth_user`, or `macOS Network Extension`. Technical engine labels appear strictly as secondary monospace metadata (`WinDivert . Zero-TUN` on Windows, `utun . Path Routing` on macOS).

## 4. Depth, Radii, Typography & Motion

### 4.1 Depth Strategy
- **Hairline-First + Whisper Diffuse Shadow:** Table rows and list rows have `box-shadow: none`. Cards and active sidebar navigation items use `1px solid var(--border-hairline)` + `var(--shadow-card)`. Floating menus, auth popover, and Tray Popover use `var(--shadow-card-lg)`. Toasts use `var(--shadow-toast)`.

### 4.2 Desktop-Converged Radius Ladder
Marketing `rounded-3xl` (`24px`) radii from the brand studio are **BANNED** inside the desktop client.
- `6px`: Chips, tags, `<kbd>`, micro-badges
- `9px - 10px`: Buttons, inputs, segmented controls (inner thumb `7px`), sidebar nav items, search inputs
- `14px`: Cards, table cards, preset app cards, inset workspace canvas top-left corner
- `16px`: Popovers, auth popover, custom Tray Popover (`304x456`), dropdown menus
- `18px`: Modal dialogs (Process Picker, Preset Library, confirmation dialogs)
- `9999px`: Status pills, toggle switches, mode badges

### 4.3 Local-Only Typography (Zero CDN / Zero Google Fonts)
- **Sans Stack:** `"Segoe UI Variable Text", "Segoe UI", -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Microsoft YaHei UI", system-ui, sans-serif`
- **Mono Stack:** `"Cascadia Mono", "SF Mono", ui-monospace, Menlo, Consolas, monospace` (used exclusively for PIDs, ports, file paths, domains, CIDRs, JSON, logs, byte counts, and engine tags).
- **Type Scale:**
  - `11.5px`: Badges, metadata, captions, mono technical subtitles
  - `12.5px`: Controls, buttons, table headers & rows, nav items
  - `13px`: Body copy, descriptions, form labels
  - `14px` (`font-weight: 600`): Section headings, card titles
  - `16px` (`font-weight: 600`): Dialog & drawer titles
  - `18px` (`font-weight: 600`, `letter-spacing: -0.015em`): Single-row page titles (`40px` page header height)
- **Numeric Discipline:** `font-variant-numeric: tabular-nums` is mandatory on every latency readout, throughput rate, PID, port, rule index, count, and timestamp.

### 4.4 Restrained Motion & Reduced-Motion Guarantee (G9)
- **Inherited Tactile Polish:**
  - Segmented control thumb (`::before` or animated indicator) uses `transition: transform 200ms cubic-bezier(0.34, 1.25, 0.64, 1)`.
  - Row actions reveal smoothly on `:hover` and `:focus-within` (`150ms ease-out`).
  - Active Sidebar nav item elevates to a white surface card (`--bg-surface`, `1px solid var(--border-hairline)`, `--shadow-card`).
- **Explicitly Excluded:** Warm color alphas, pastel icon tiles, icon rotation on hover, decorative rainbow gradients on controls/dividers/progress bars.
- **Reduced Motion (`@media (prefers-reduced-motion: reduce)`):** Disable all spring transitions (`transition-duration: 0.01ms`), breathing status dots, radar sweeps, and skeleton pulse/shimmer animations.

### 5.2 Orthogonal Takeover Mental Model (TitleBar & Tray Popover)
Users answer exactly two orthogonal questions:
1. **Mode (`Rule | Global | Direct`):** How captured traffic is routed.
2. **Takeover:** Which traffic enters Bypax:
   - **System Proxy** (independent switch pill): Proxy-aware apps (browsers). Coexists with transparent takeover.
   - **App Proxy / TUN (`Off | App Proxy | TUN`)** (mutually exclusive 3-way segmented control, no redundant "Capture" prefix in TitleBar; labeled `App Proxy / TUN` in Tray Popover & Compact popover): Structural mutual exclusion between `App Proxy` and `TUN`.
     - Switching shows `switching` spinner (`12px`) and locks sibling options.
     - Failure snaps the slider **back** to its prior position, shows an inline error link, and emits a danger Toast.
     - Selecting `App Proxy` with 0 enabled rules is permitted and displays an amber hint dot linking to the Preset App Wall.
     - Selecting `App Proxy` or `TUN` while no session helper is connected opens an anchored `320px` **Inline Auth Popover** (Windows: single GUI-bound `Authorize for this session (UAC)` option with zero background service registration; macOS: `Install background helper` via `launchd`) and resumes the toggle after approval.

## 7. Pre-Paint Anti-Flash & Native WebView2 Readiness (R1)

Preventing a white flash on dark systems requires BOTH native window initialization and pre-paint HTML synchronization:
1. **Native Window Background (Owned by `src-tauri/tauri.conf.json` & Tauri Startup):**
   - `src-tauri/tauri.conf.json` MUST set `"backgroundColor": "#F6F7F9"` on the main window definition so WebView2 never paints an unstyled default white backing surface before HTML loads.
   - Tauri window & tray-popup initialization (`src-tauri/src/lib.rs` and `src-tauri/src/tray.rs`) MUST resolve the persisted/system theme before calling `.show()` and apply native `set_background_color` (`#0B1120` when Dark or System-Dark, `#F6F7F9` when Light; Tray Popover `#161B22` Dark / `#FFFFFF` Light).
2. **Synchronous Pre-Paint Inline Script (`index.html`):**
   - `index.html` MUST include a minimal synchronous inline `<script>` before stylesheet/app mount that reads `localStorage.getItem('bypax-theme')` (fallback `matchMedia('(prefers-color-scheme: dark)')`), toggles `document.documentElement.classList.toggle('dark', isDark)`, and sets `document.documentElement.style.backgroundColor` to `#0B1120` (Dark) or `#F6F7F9` (Light) (or `#161B22`/`#FFFFFF` when `?view=tray`) immediately before first paint.

## 8. Studio Slate Anti-Drift Prohibition Checklist (Gate A / Gate B)

Every PR and pre-release audit MUST verify zero violations across these 12 rules:

1. **Zero Warm-Theme Leakage:** Reject any occurrence of `rgba(70,52,28`, `rgba(255,240,220`, `#fbfaf8`, `#1f1e1c`, `#cf4529`, or `04-notion-arc-warm` warm alphas in `src/`.
2. **Zero Pure Black:** Reject `#000000` or `#000` in CSS/TSX UI styles (SVG `<mask>` black knockout inside `BrandLogo.tsx` and macOS template PNG assets excepted).
3. **Radius Ceiling:** Reject Tailwind `rounded-3xl` or any `border-radius > 18px` on UI surfaces/controls (excluding `9999px`/`rounded-full` pills and the Logo squircle).
4. **Zero External Network Assets (G8):** Reject `fonts.googleapis.com`, `fonts.gstatic.com`, `cdn.tailwindcss.com`, or any remote font/CSS/script URL in `index.html`, `src/`, or `src-tauri/tauri.conf.json` CSP.
5. **Rainbow Isolation (G10):** Reject BOTH raw Logo rainbow hexes (`#38BDF8`, `#4ADE80`, `#FACC15`, `#FB923C`, `#F43F5E`, `#3B82F6`) AND 105%-saturation baked Logo hexes (`#33BFFD`, `#46E27F`, `#FFCF10`, `#FF9238`, `#F93A5B`, `#3681FB`) anywhere outside `src/components/BrandLogo.tsx`, `scripts/generate-bypax-assets.mjs`, `src-tauri/icons/**`, `assets/**`, and `public/favicon.svg` (sole documented token exception: `#38BDF8` for Dark `--accent-focus` in `src/styles/tokens.css` / `src/index.css`).
6. **Semantic Token Discipline:** Reject hardcoded hex/rgb colors inside `src/features/**` and `src/components/**` (except `BrandLogo.tsx` and native Windows close-button hover `#C42B1C`).
7. **Contrast Floor Guards (G4):**
   - Light chrome (`#F6F7F9`): NEVER use `--text-tertiary` (`#64748B`, 4.44:1 fail) for informative text anywhere on chrome surfaces -- specifically, Sidebar trailing counts/badges and TitleBar labels/throughput MUST use `--text-secondary` (`#475569`) or `--text-primary` (`#0F172A`).
   - Tray Popover: MUST use `--bg-surface` (`#FFFFFF` / `#161B22`) as root surface and `--bg-subtle` (`#F8FAFC` / `#1C2128`) for inner cards (never `--bg-chrome`).
   - Danger Banners & Red Chips: MUST use `--danger-text-on-bg` (`#B91C1C` Light, 5.9:1 on `#FEF2F2`; `#FF7B72` Dark) -- NEVER `--danger-text` (`#DC2626`, 4.40:1 fail) on `--danger-bg`.
   - Dark mode: NEVER use `#6E7681` (~4.0:1 fail); use `--text-tertiary: #7D8590` (~5.0:1).
8. **Mandatory Dark Canvas Hairline:** Verify `.dark` inset workspace canvas visibly renders `1px solid var(--border-hairline)` along top and left edges.
9. **Zero Fixed Table `min-width` (G1/G2):** Reject `min-w-[...]` or CSS `min-width` on all tables and table scroll wrappers; zero horizontal overflow at `1440x900`, `1100x760`, and `940x620` in EN and zh-CN.
10. **Mark Placement Discipline:** TitleBar and Tray Popover (`< 48px`) use `<BrandLogo variant="monochrome" />`; `<BrandLogo variant="color" />` appears ONLY at `>= 48px` (About card, empty states).
11. **Reduced Motion Compliance (G9):** Verify `prefers-reduced-motion: reduce` suppresses all spring curves, pulsing dots, and skeleton animations.
12. **ASCII, Locale Parity & Brand Hygiene (G11/G12):**
    - 100% pure 7-bit ASCII in all `*.ts`, `*.tsx`, `*.js`, `*.mjs`, `*.css`, `*.rs`, `*.yml`, `*.ps1` files.
    - Exact 100% key set parity between `src/locales/en.json` and `src/locales/zh-CN.json`.
    - Zero `sing-box`, `portline`, `bypath`, or `macOS Network Extension` in user-facing UI strings, banners, titles, or localStorage keys.
